# ShopAgent v2 项目目标

## 一句话

基于高星开源全栈 Agent 模板，把商城订单与售后系统改造成一个真实可运行、可评测、可解释、可人工审批的 Agent 作品。

## 产品闭环

```text
客户提出售后问题
  -> Agent 理解诉求
  -> 查询当前用户的订单、物流、工单
  -> Hybrid RAG 检索政策并引用来源
  -> 输出诉求、证据、缺失信息、建议、风险、置信度
  -> 高风险动作生成待审批提案
  -> 管理员批准或拒绝
  -> 确定性服务修改工单和订单
  -> 写入审计与 Agent Trace
```

## 必须满足

- FastAPI、SQLAlchemy async、PostgreSQL、Alembic。
- Redis、Celery、幂等和可重试的后台基础设施。
- JWT、RBAC、用户级数据隔离。
- 订单、库存、支付、售后、留言、提案、审批的明确模型。
- 订单和工单合法状态机。
- DeepSeek + LangGraph 工具规划。
- 至少三个只读业务工具和一个高风险提案工具。
- pgvector + BM25 + RRF 政策检索，返回来源。
- 高风险动作不可由 Agent 直接执行。
- request_id、Agent Run、工具步骤、Token、延迟、错误和停止原因可追溯。
- 30 条售后评测，比较三套方案。
- 售后工作台、自动化测试、README、架构说明、演示材料。
- 密钥不进入 Git。

## 非目标

- 不接真实支付渠道。
- 不做安全攻防主题。
- 不为了简历硬凑 Multi-Agent。
- 不训练或微调大模型。
- 不把模拟物流说成真实生产物流。
